# Hamstring Stretching

A simple, bilingual web app that guides users through a hamstring stretching session with a timer, exercise instructions, and video previews.

**[Open the app](https://rozciaganie-kulszowo-goleniowych.piotrowiakp.chatgpt.site)**

## Features

- Polish and English interface with a saved language preference.
- A 25-minute guided session covering both legs and a final rest.
- One-minute exercise intervals, pause controls, and step navigation.
- Video previews and links to the corresponding moments in the original video.

## Educational purpose

This is a non-commercial project created for educational purposes. It demonstrates how a web interface can help users follow an existing exercise routine.

## Exercise guidance

The app is an educational aid, not personalized medical advice. Use the original video as a reference for positioning and movement. Work within a comfortable range and stop if you experience pain, tingling, or numbness.

## Run locally

Open `dist/index.html` in a modern browser. Keep the `dist/motions` folder alongside it so the video previews and images can load.
